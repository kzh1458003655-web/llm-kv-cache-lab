# 租机脚本的本机预检

服务器尚未租用。本目录是 RTX 4060 Laptop 8GB 上的脚本预检，不是 4090D 的结果。

同一份 hot_scan 负载，原版和 reuse2 各 128 请求，缓存预算 128MiB，输出 32 token。两者完成 128/128，输出 token 哈希匹配 128/128；原版命中 52,224 token，reuse2 命中 69,632 token，多复用 17,408。16 次热点返回原版均为 0，reuse2 均为 1088 token。

计时为预热及缓存重置后，单请求同步 generate 调用的总耗时。reuse2 相对原版仅变化 -0.193%；只是一组对照，不能证明加速。没有开启逐事件观察器，也不是流式 TTFT 或线上吞吐评测。

首次原版启动因默认显存占比 0.92 超过可用显存而失败，记录在 failed-startup。改用显式 0.60 后成功。失败未从历史中删除。

来源使用完整 LooGLE 固定 revision，文档截断及到达顺序由程序安排。目录只发布请求来源 ID、哈希及测量，不含完整提示或文档。测量和审核元数据按 CC0 发布；原始数据和模型保持各自许可。
