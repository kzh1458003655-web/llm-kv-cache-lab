# 开发路线

## 阶段一：真实推理与可测基线

- [ ] 确定模型、vLLM 版本和可用 GPU 配置。
- [ ] 启动推理服务，记录可复现的环境信息。
- [ ] 跑通三类基础工作负载与原版指标。

## 阶段二：缓存可观测性

- [x] 定义缓存事件格式和无 GPU 测试。
- [ ] 接入真实 vLLM 缓存事件。
- [ ] 校验事件记录与引擎请求级指标一致。

## 阶段三：管理策略与评测

- [ ] 根据基线表现确定一个具体策略改动。
- [ ] 实现原版/改进版切换和正确性测试。
- [ ] 完成同条件 Benchmark、重复实验和退化分析。

## 阶段四：展示与论文材料

- [ ] 完成模型交互和缓存事件回放页面。
- [ ] 展示策略对比和实验配置。
- [ ] 整理系统设计、测试方法、结果及局限。

## 最低完成标准

真实模型运行、Block 级可观测性、一项实际策略改动、三类工作负载的公平对比、可展示的 Web 页面。策略不必在所有场景取得正收益，但需要解释测得的结果。
